How it works

From a task description to installed skills

  1. ClassifyMap the task to domains such as reverse engineering or security
  2. SearchGitHub repo search, code search for filename:SKILL.md, and the tool's own org
  3. ShortlistRank on stars and description match, keep the top 8
  4. EvaluateRead each file tree and SKILL.md frontmatter, then score 0–100
  5. ScanCheck every file for download-and-run, secret theft and prompt injection
  6. InstallCopy into each agent's skills folder and record the commit in a lockfile

Works with these agents, and any other you add in ~/.btr/agents.json:

  • Claude Code
  • OpenAI Codex
  • Gemini CLI
  • OpenCode
  • ~/.agents/skills

Popularity is logarithmic, so 50k stars is not ten times better than 5k. Relevance counts your own words more heavily than generic domain words, and tool names you mention count most. A platform mismatch costs 15 points, so an Android-only skill does not win a Windows task.

Skills published by the tool's own GitHub organisation get 10 extra points. Trust flags catch repos that gained thousands of stars in a few weeks or have almost no forks.

Safety scanner

Blocking the right skills

A skill is a set of instructions your agent follows with your permissions. Before anything is written, btr scans every file for download-and-execute commands, encoded payloads, credential theft, prompt injection, disabled safety flags, token exfiltration, persistence and bundled binaries. High-severity findings block the install unless you pass --force, and updates are scanned again.

FAQ

Questions

What is an agent skill?

An agent skill is a folder with a SKILL.md file (instructions plus optional scripts) that coding agents such as Claude Code, Codex and Gemini CLI load to get better at a specific kind of task, for example reverse engineering or security audits.

Which coding agents does btr install skills into?

Claude Code, OpenAI Codex, Gemini CLI, OpenCode and the shared ~/.agents/skills folder. Other agents can be added in ~/.btr/agents.json.

Is it safe to install skills found on GitHub?

Skills run with your permissions, so btr scans every downloaded file, blocks high-severity findings, and asks before installing. The scanner is a heuristic, so review anything you do not recognise.

How does btr choose the best skill?

It scores each candidate repo from 0 to 100 on popularity, relevance to your task, SKILL.md quality, freshness and repo health, adds 10 points for skills from the tool's own organisation, and subtracts points for unsafe content, suspicious star growth or the wrong platform.

Can I use it from inside Claude Code?

Yes. After btr self-install, type /btr followed by your task. Claude shows the top picks with their scores and findings and installs only after you agree.

Is btr free?

Yes. It is open source under the MIT license and needs only Node.js 18 or later.
